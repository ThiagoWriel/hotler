# Hotler 🏨

O **Hotler** é um sistema de gerenciamento hoteleiro (PMS - Property Management System) moderno e intuitivo, desenvolvido para facilitar a administração de hotéis e pousadas. O projeto foca em uma experiência de usuário fluida ("Rich Aesthetics") e eficiência operacional.

## 🚀 Funcionalidades

### 🛏️ Gestão de Quartos

- **CRUD Completo**: Criação, Leitura, Atualização e Deleção de quartos.
- **Status em Tempo Real**: Controle visual de limpeza (Limpo/Sujo) e manutenção.
- **Controle de Ocupação**: Visualização rápida de quartos ocupados ou disponíveis.
- **Filtros e Ordenação**: Organize a visualização por número, tipo ou status.

### 👥 Gestão de Clientes

- **Cadastro Detalhado**: Registro de hóspedes com dados pessoais e observações.
- **Edição Fácil**: Atualize informações de clientes rapidamente.
- **Histórico**: Base para controle de reservas futuras.

### 📊 Dashboard e Outros Módulos

- **Dashboard**: Visão geral dos indicadores do hotel.
- **Reservas**: Módulo dedicado ao controle de check-in/check-out.
- **Financeiro**: Acompanhamento de receitas e despesas.

## 🛠️ Tecnologias Utilizadas

- **Frontend**: [React.js](https://reactjs.org/)
- **Backend as a Service**: [Supabase](https://supabase.com/) (Banco de dados PostgreSQL e API em tempo real)
- **Roteamento**: [React Router](https://reactrouter.com/)
- **Estilização**: CSS3 Moderno (Variáveis CSS, Flexbox, Grid, Transições)
- **Fontes**: Google Fonts (Poppins)
- **Ícones**: Material Icons
